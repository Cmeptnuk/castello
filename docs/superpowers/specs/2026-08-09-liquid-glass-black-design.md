# Liquid glass black: каркас страниц и раскладка

Дата: 2026-08-09

## Задача

На широком экране контент каждого слайда сидит в узкой центральной колонке
(`max-w-2xl` … `max-w-5xl`), по краям — мёртвое поле в несколько сотен пикселей.
Декора нет: только фоновый шум, три размытых пятна (`src/App.tsx:477`),
курсорный шлейф и волосяные градиенты на карточках. Страница читается пустой.

Две жалобы, обе надо закрыть: «пусто» и «элементы только по середине».

## Решение

1. **Шасси страницы** — постоянный слой по краям экрана: угловые засечки,
   вертикальные подписи, счётчик слайда, точки-навигация, нижняя строка, сетка.
   Виден на всех шести слайдах и на всех размерах экрана.
2. **Материал liquid glass black** — поверхности собираются из размытого
   тёмного стекла с направленным кантом и бликом под курсором, вместо нынешних
   плоских `bg-white/[0.03]`.
3. **Раскладка под ширину экрана** — панели слайдов расширяются, заголовки
   уезжают в боковую колонку, центральная симметрия ломается.

Палитра: монохром плюс discord-индиго `#5865F2` — цвет уже есть на кнопке
Discord (`src/App.tsx:931`).

## Материал

Токены объявляются в `src/index.css` рядом с `@theme`:

```
--glass-bg          rgba(255,255,255,0.045)
--glass-bg-strong   rgba(255,255,255,0.07)
--glass-blur        blur(24px) saturate(160%)
--glass-ring-top    rgba(255,255,255,0.22)
--glass-ring-side   rgba(255,255,255,0.07)
--glass-ring-bottom rgba(255,255,255,0.03)
--glass-shadow      0 16px 48px -12px rgba(0,0,0,0.7)
--glass-tint        rgba(88,101,242,0.10)
```

Стеклом, а не полупрозрачным прямоугольником, поверхность делают три вещи.

**Направленный кант.** `border` светится одинаково по всему периметру — так
стекло не выглядит. Кант рисуется градиентом сверху вниз и вырезается маской:

```css
.glass::after {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  padding: 1px;
  background: linear-gradient(
    180deg,
    var(--glass-ring-top),
    var(--glass-ring-side) 30%,
    var(--glass-ring-bottom)
  );
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor;
  mask-composite: exclude;
  pointer-events: none;
}
```

Источник света один и сверху: ярко по верхней кромке, гаснет к нижней.

**Блик под курсором.** `radial-gradient` в `::before`, центр привязан к
переменным `--mx` / `--my`, которые пишутся на элемент при `pointermove`.

**Подхваченный тинт.** Индиго не назначается поверхностям — три существующих
фоновых пятна (`src/App.tsx:477`) перекрашиваются в `rgba(88,101,242,…)` и
остаются под стеклом. `backdrop-filter` размывает их в саму поверхность, и
панель окрашивается неравномерно, по-разному в разных местах экрана. Это и
отличает liquid glass от заливки: не назначенный цвет, а подхваченный.
Параллакс пятен от курсора сохраняется.

## Правило стека

`backdrop-filter` стоит дорого и линейно по количеству элементов — именно
поэтому он сейчас заглушен на тач-устройствах (`src/index.css:110`). Стёкла не
громоздятся друг на друге:

| Уровень   | Блюр    | Что                                              |
| --------- | ------- | ------------------------------------------------ |
| Шасси     | нет     | сетка, засечки, подписи, счётчик, точки, строка   |
| Панель    | да, 1   | навбар, панель слайда, корзина, мобильное меню    |
| Карточка  | нет     | тинт, кант, блик — внутри уже размытой панели     |

Максимум два размытых слоя на экране одновременно. В каталоге это одна
размытая поверхность вместо девяти.

Правило `@media (hover: none)` в `src/index.css:110-119` переписывается:
вместо глобального `backdrop-filter: none` по атрибуту класса — точечное
отключение блюра у карточек, панелям блюр остаётся с радиусом 16px вместо 24px.
`.decor-orbs` на тач-устройствах остаются скрытыми; их роль забирает сетка,
которая рисуется градиентами и не требует блюра.

## Шасси страницы

Компонент `PageChrome` рисуется один раз, вне `.slide-viewport`, поэтому не
участвует в fade-переходах между слайдами и не перерисовывается при их смене.
Лежит в `fixed inset-0 pointer-events-none`; интерактивные части получают
`pointer-events-auto` точечно.

```
┌──────────────────────────────────────────────────────────┐
│  ┌ ─                                      02 / 06    ─ ┐ │
│                                                          │
│  C   ╭────────────────────────────────────────────╮  ▬  │
│  A   │ ░ стекло: блюр + кант + подхваченный тинт ░│  ·  │
│  S   │  Украшения  ┌────┐┌────┐┌────┐┌────┐┌────┐ │  ·  │
│  T   │  Наборы     └────┘└────┘└────┘└────┘└────┘ │  ·  │
│  E   │  ─────────  ┌────┐┌────┐┌────┐┌────┐┌────┐ │  ·  │
│  L   │  Без Nitro  └────┘└────┘└────┘└────┘└────┘ │  ·  │
│  L   ╰────────────────────────────────────────────╯     │
│  O        ◜ индиго-пятно под панелью, размыто ею ◝  К   │
│  ·                                                   А   │
│  └ ─   t.me/CastelloShop_bot        ↑ ↓ листать   ─ ┘ Т │
└──────────────────────────────────────────────────────────┘
```

| Элемент              | Где                | Как                                                                 |
| -------------------- | ------------------ | ------------------------------------------------------------------- |
| Угловые засечки      | 4 угла             | L-образные, 1px, `white/[0.08]`, отступ 20px / 32px от `sm`          |
| Подпись слева        | левый край         | `CASTELLO SHOP`, `vertical-rl`, 10px, `tracking-[0.4em]`, `white/[0.12]` |
| Подпись справа       | правый край        | имя раздела, `vertical-rl`, `text-[#5865F2]/40`, crossfade при смене |
| Счётчик              | правый верх        | `02 / 06`, `font-mono`, текущая цифра `white/40`, остальное `white/[0.15]` |
| Точки-навигация      | правый край, центр | 6 штук; активная — вытянутое индиго-тире, прочие `white/15`; кликабельны |
| Нижняя строка        | низ                | слева `t.me/CastelloShop_bot`, справа `↑ ↓ листать`, 10px `white/[0.12]` |
| Сетка                | весь экран         | два `repeating-linear-gradient` с шагом 96px, `white/[0.015]`        |

Сетка гасится к центру радиальной маской, чтобы не лезть под текст: гуще по
краям, растворяется в середине. Чистый CSS без блюра — по стоимости отрисовки
это заметно дешевле нынешних `.decor-orbs`.

Точки-навигация — единственная интерактивная часть шасси, вызывают `goToSlide`.
Остальное декоративно и скрыто от скринридеров через `aria-hidden`.

Мобильные (< `sm`): засечки 20px, сетка с шагом 64px, вертикальные подписи 8px,
из нижней строки убирается адрес бота — остаётся только подсказка навигации.

## Раскладка по слайдам

Шасси занимает края экрана, панель слайда живёт внутри него, между ними воздух.
Панели шире нынешних колонок, симметрия «всё по центру» ломается.

| Слайд    | Сейчас      | Становится                                                        |
| -------- | ----------- | ----------------------------------------------------------------- |
| Главная  | `max-w-4xl` | без панели; стеклянный бейдж и стеклянная строка фактов внизу      |
| Каталог  | `max-w-5xl` | `max-w-7xl`, фильтры в левую колонку от `lg`, сетка 5 колонок от `xl` |
| Процесс  | `max-w-4xl` | `max-w-6xl`, заголовок в левую колонку, таймлайн шире              |
| Оплата   | `max-w-2xl` | `max-w-5xl`, карта слева, способы оплаты столбцом справа от `lg`   |
| FAQ      | `max-w-2xl` | `max-w-5xl`, заголовок слева липким блоком, вопросы справа         |
| Discord  | `max-w-3xl` | `max-w-5xl`, две колонки: приглашение и финальный CTA              |

Главная остаётся центрированной сознательно — герой читается лучше свободным.
Пустоту под ним забирает стеклянная строка фактов: «выдача 10–15 мин · карты РФ,
СБП, крипта · без Nitro и с Nitro». Кнопка Telegram остаётся сплошной белой:
единственная непрозрачная поверхность на сайте, поэтому и цепляет взгляд.

Ниже `lg` все двухколоночные раскладки схлопываются в одну колонку — порядок
следования в разметке выбирается так, чтобы на телефоне заголовок шёл первым.

## Ограничения, которые нельзя нарушить

**LCP.** `src/index.css:40` и `src/App.tsx:318` — на первом экране ничего не
появляется через `opacity`, иначе Chrome навсегда исключает элемент из
кандидатов на LCP. Стекло героя въезжает `transform` и нарастанием радиуса
блюра, не прозрачностью.

**Гидратация.** Разметка с сервера и первый клиентский рендер обязаны совпасть
(`src/entry-server.tsx`, пререндер в `scripts/prerender.mjs`). Позиция курсора,
`matchMedia` и корзина уже разведены через `useSyncExternalStore` — блик под
курсором стартует из нейтральной позиции и не читает `window` при рендере.

**Инлайн CSS.** Собранный CSS вшивается в HTML (`vite.config.ts:9`), поэтому
каждый килобайт стилей лежит в критическом пути. Токены и общие классы стекла
объявляются один раз, без дублирования утилит по компонентам.

**Пререндер.** Все шесть маршрутов собираются статически. `PageChrome` обязан
рендериться на сервере — включая правильный номер слайда и имя раздела для
маршрута.

## Правки в коде

**Курсор из React убирается.** `onMouseMove` (`src/App.tsx:448`) кладёт позицию
в `useState`, из-за чего каждое движение мыши перерисовывает всё приложение
вместе с сеткой карточек. Позиция переезжает в CSS-переменные на корневом
элементе через ref; параллакс пятен и блик на стекле читают их из CSS. React из
цикла движения мыши уходит совсем.

**`App.tsx` разбирается.** Сейчас 974 строки, и работа добавит ещё. Выносится в
`src/components/`: `PageChrome`, `PriceGrid`, `FaqItem`, `TiltCard`,
`CursorTrail`, `SlideFade`, `SectionHeading`; логика корзины — в `src/cart.ts`,
данные каталога и FAQ — в `src/data.ts`. Разметка слайдов остаётся в `App.tsx`.

## Проверка

- `npm run build` проходит: `tsc -b`, сборка клиента, SSR-сборка, пререндер
  шести маршрутов.
- `npm run lint` без ошибок.
- Все шесть маршрутов открываются напрямую, без предупреждений о гидратации в
  консоли.
- На каждом слайде в любой момент не больше двух элементов с `backdrop-filter`.
- Первый экран не красится прозрачным: у элементов героя нет стартовой
  `opacity: 0`.
